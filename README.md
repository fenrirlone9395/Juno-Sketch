# JUNO Sketch v0.1.6

JUNO-DS用の小さなPython/Tkinter MIDIシーケンサーです。16トラック、ピアノロール、通常／三連符Grid、Slip、Velocity、SMF Type 1、JSONプロジェクトを実装しています。

## Macでの起動

Python 3.12とTkを推奨します。python-rtmidi 1.5.8のmacOS用ビルド済みwheelを使える構成です。Python 3.14ではソースビルドが必要になる場合があります。macOS付属の古いPythonは対象外です。Apple SiliconではPythonと依存パッケージのアーキテクチャを揃えてください。

初回の依存導入と開発実行：

```bash
cd juno-sequencer
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

内部プレビューはmacOS標準AudioToolboxのDLSシンセを使用します。FluidSynth、SoundFontのダウンロードは不要です。JUNO-DSの音色を再現するものではなく、Program Changeに対応するGM相当の確認音源です。内部プレビューはGM基本バンクのMSB 121（メロディー）／120（ドラム）、LSB 0を音源へ送信します。JUNO固有バンクや派生LSBは、内部音源への送信時にGM基本バンクへ正規化します。

## .appの作成

Mac上で `scripts/build_macos.command` を実行します。Finderでのダブルクリックも可能です。初回はPython環境とネット接続が必要です。

```bash
bash scripts/build_macos.command
```

`dist/JunoSketch.app` ができます。これをApplicationsへコピーすると、以後はターミナルを開かずダブルクリックで起動できます。Python、mido、rtmidi、TkはPyInstallerが同梱し、内部音源はmacOSのフレームワークを利用します。

ビルドは対象Mac上で行ってください。LinuxからmacOS .appをクロスビルドする構成ではありません。署名・公証・他のMac向け配布インストーラーは含みません。必要なら `JUNO_PYTHON=/path/to/python3 bash scripts/build_macos.command` でPythonを指定できます。

## 操作

- 左で16トラックを選択。Channelは1〜16、Programは1〜128表示（内部MIDI値は0始まり）。Bankは0〜127。
- 設定変更後は「設定を適用・音色送信」。Default Velocityもここで変更します。
- 空白をダブルクリックして作成。ノート中央をドラッグして時刻／音程移動、右端7pxで長さ変更。
- Shiftクリックで選択を追加／解除。空白から囲んで複数選択。Shift＋囲みで追加。
- Delete／Backspaceで選択ノートを削除。右クリックで対象ノートを削除。
- Grid／Slipと分解能は上部。1/4、1/8、1/16、1/32とそれぞれのT（三連符）。同じトラック内で混在できます。
- Velocityレーンのバーを上下ドラッグ。複数選択時は選択全体に同じ値を設定します。
- Spaceで再生／停止。ルーラークリックで開始位置、`|◀`で先頭。
- BPMを入力して「適用」。入力欄にフォーカス中のSpaceやDeleteは編集操作になります。
- Cmd+Z／Cmd+Shift+ZでUndo／Redo。Cmd+S保存、Cmd+O読込、Cmd+N新規。メニューからも利用可能。
- ホイールで上下、Shift＋ホイールまたは下部スクロールバーで左右移動。
- 右方向は最低8小節。末尾のノートに合わせて自動延長します。全128音の音域。

## JUNO-DS接続

1. JUNO-DSをUSB接続し、macOSのAudio MIDI設定等で認識されることを確認。
2. 本体側で16パートが受信できるPerformanceと各パートのMIDI受信チャンネルを設定。
3. 出力をJUNO-DSへ切替。「ポート更新」を押し、JUNO-DSのポートを選択。
4. 対象トラックのBank MSB／LSB／Programを本体のMIDI Implementation／音色表に合わせて設定し、「設定を適用・音色送信」。

ポート選択肢はmacOSのMIDIポート一覧です。自動で最初のポートへ送信することはありません。意図したJUNO-DSポートを選んでください。USBドライバーの要否は本体設定／OSとの組合せに依存します。本体の音色名データベースや固有SysExは含みません。同一チャンネルに複数トラックを割り当てると音色設定等を共有します。独立したパートには異なるチャンネルを割り当ててください。

## 保存と読込

独自形式は `.juno.json`。ノート、トラック設定、BPM、テンポ情報、グリッド、出力ポート、選択トラック、ウィンドウ位置／大きさ、スクロールを保存します。新規・読込・終了時には未保存の編集を確認します。プロジェクトは一時ファイルを経由して置換します。

SMF出力はType 1、PPQ 960。テンポ／拍子のconductor＋16のMIDIトラック（計17 SMFチャンク）です。MIDIトラックのBank MSB→LSB→Programを先頭に書き込みます。ノート、Velocity、チャンネル、途中のCC／Program／Pitch Bend／Aftertouchも保持します。読込では元のPPQを960に変換します。Type 0も読み込めますが、16を超える「元トラック×チャンネル」があるファイルとType 2／SMPTE divisionは明示的に拒否します。元の解像度が960の約数でなければ1tick未満の丸めが生じます。

エディターは拍子設定と途中の拍子変更に対応し、SMFの拍子情報も表示に反映します。途中のテンポ変更は再生・再出力できます。BPMを変更するとテンポマップは一定テンポに置き換えます。SysEx、歌詞など対象外のメタイベントは保持しません。空の元トラックの配置や同音の重なりの識別など、あらゆるSMFの完全な往復は保証しません。

## 構成

- `models/project.py`：Project／Track／Note、PPQ、グリッド
- `ui/main_window.py`：アプリ、トラック一覧、保存、出力切替
- `ui/piano_roll.py`：ピアノロール、選択、ドラッグ、Velocity
- `midi/output.py`：MidiOutputの抽象インターフェース
- `midi/internal_preview.py`：macOSシステム音源
- `midi/juno_ds.py`：mido／rtmidiによるJUNO出力
- `midi/player.py`：独立スレッドと単調増加時計による再生
- `midi/smf.py`：SMF読み書き
- `services/`：Undo／Redo、JSON保存

再生は開始時のスナップショットです。再生中のノート編集は次回再生から反映します。ソロ／ミュートは即時反映します。タイミングは絶対時刻を基準に待機し、イベントごとのsleep誤差の累積を避けます。OS／USBのジッターやレイテンシーを保証するハードリアルタイム実装ではありません。停止と出力切替時にSustain Off／All Notes Off／All Sound Offを全チャンネルに送信します。将来の出力はMidiOutputを実装して追加できますが、現状は2系統だけです。

## v0.1.2：音色名をトラック名へ適用

トラック設定のBank MSB／LSB／Programから、JUNO-DS公式Parameter Guideの音色表を参照します。DS 184音色、PRST 1,088音色、GM 256音色とドラム39キット（計1,567件）を同梱し、実行時にネット接続は不要です。

1. Bank MSB／LSB／Programを入力します。直下の `JUNO:` 表示に音色名が出ます。
2. 「音色名をトラック名へ適用」を押すと、入力済みのトラック設定と音色名を適用します。このボタン自体はMIDIを送信しないため、JUNO未接続でも使えます。
3. 「音色変更時に名前を追従」をオンにすると、「設定を適用・音色送信」で音色設定を変える際にトラック名も更新します。追従はトラックごとに保持します。
4. 任意の名前は `Name` 欄に入力し、「設定を適用・音色送信」で確定します。任意名を使い続ける場合は追従をオフにしてください。

例：MSB **87**／LSB **73**／Program **1** → **Grand Pno DS**。同じProgram 1でもMSB 87／LSB 64なら **88StageGrand** です。画面はProgram 1–128、内部マップはMIDI値0–127です。

ユーザー音色・サンプル・拡張音色の名前は本体の内容次第なので推測しません。未登録の組合せではトラック名を保持します。任意入力のMSB 0／LSB 0は「未登録」です。v0.1.3以降、新規トラックの初期値はGM基本バンクです。名前表示は現在のトラックに設定されているBank／Programの対応表を参照します。内部音源はGM基本音色のプレビューであり、JUNO固有音色やGM派生音色そのものの再現ではありません。曲途中のProgram Changeイベントには追従せず、トラック先頭の音色設定を使います。

トラック名の変更はUndo／Redoに対応し、プロジェクトとSMFのトラック名に保存します。追従設定は独自プロジェクトにのみ保存します。v0.1／v0.1.1のプロジェクトは追従オフで読み込み、既存名を維持します。

出典：Roland JUNO-DS Parameter Guide（2015版）、66–76ページ、Patch List／Drum Kit List。
https://static.roland.com/assets/media/pdf/JUNO-DS_ParamGuide_e01_W.pdf
`assets/juno_ds_patches.json` に番号対応の事実データのみを格納しています。マニュアル本文・PDF・音声データは同梱していません。音色名はRolandの製品表記です。PDFの曲線アポストロフィ2件はSMF保存互換のためASCIIへ正規化しています。

更新時は `assets/`、`services/`、`models/`、`ui/` と `JunoSketch.spec` を含めてソース全体を更新してください。音色マップはspecで.app内へ同梱します。

```bash
.venv/bin/python -m PyInstaller --clean --noconfirm JunoSketch.spec
```

## v0.1.3：出力先に応じた基本バンク切替

| 出力先 | メロディー MSB / LSB | ドラム MSB / LSB |
|---|---|---|
| Internal Preview | 121 / 0 | 120 / 0 |
| JUNO-DS（初回：PRST） | 87 / 64 | 86 / 64 |

新規プロジェクトはInternal PreviewのGM基本バンクから開始します。チャンネル10またはドラム用MSB（86／120）を持つトラックをドラムとして判定します。

出力先の切替時は再生・試聴を停止し、旧出力を消音して閉じ、全16トラックのバンクを変更します。Program番号、ノート、Velocity、チャンネル、曲途中のMIDIイベントは維持します。切替後の音色名は表示に反映され、「名前を追従」オンのトラック名も更新します。手動名は維持します。

JUNOへ初めて切り替えるとPRSTバンクになります。その後JUNO側で設定したバンクはトラックごとに覚え、Internalを経由してJUNOへ戻った際に復元します。Internalへ切り替える際は毎回GM基本バンクへ戻します。出力先が同じままMIDIポートだけを変えた際は、バンクを書き換えません。JUNOのバンク履歴も独自プロジェクトに保存し、Undo／Redo対象です。

ポート選択済みなら切替直後に16トラック分のBank Select MSB→LSB→Program Changeを送信します。JUNOのポート未選択時は設定のみ変更し、ポート選択後に送信します。接続・初期化エラーはステータスに表示し、選択状態と設定を残して再接続後の再試行を可能にします。

GM→PRSTはBankの切替であり、音色名を照合した楽器の自動変換ではありません。同じProgram番号でもGMとJUNO PRSTでは別の音色になります。また、読み込んだ曲途中のBank Select／Program Changeは保持するため、再生中に先頭の音色設定を上書きする場合があります。

旧プロジェクトは保存されていた値を維持して読み込みます。新しい基本バンク制御を適用するには出力先を一度切り替えてください。SMFには現在の出力先で有効な先頭バンク設定を保存し、出力先ごとの履歴は独自プロジェクトだけに保存します。

内部プレビューへの実際のMIDI送信でもMSB 121／120とLSB 0を使います。未対応のJUNOバンク番号はGM基本バンクへ正規化します。ただし、macOS標準DLS音源のGM2派生音色・全ドラムキットの忠実な再現は保証しません。macOS実発音・JUNO実機での最終確認は必要です。

## v0.1.4：Time Signature

上部2段目の「拍子 4/4…」ボタンで拍子設定画面を開きます。

- 小節1に3/4や6/8等を設定すると、曲の先頭拍子を変更します。
- 小節5に7/8等を設定すると、その小節から拍子を変更します。変更一覧の選択で内容を読み込めます。
- 分子は1〜255、分母は1・2・4・8・16・32・64・128・256です。分母はSMFの仕様に合わせて2の累乗です。
- 途中の変更を削除できます。先頭拍子は削除せず、別の値へ設定し直してください。
- ピアノロール／All Tracksの小節線、Bars|Beatsルーラー、表示範囲、再生位置の小節・拍番号に反映します。
- 6/8は8分音符6拍として表示し、BPMは従来どおり4分音符基準です。付点4分音符BPMやメトロノームは実装していません。
- Gridは音価（1/16等）を維持し、各小節頭を基準にスナップします。三連符グリッドも小節ごとに描画します。
- 拍子を変更してもノート／テンポ変更イベントの絶対tickは移動しません。後続の拍子変更は元の小節番号を維持して再配置します。
- 独自プロジェクトとSMFに拍子変更マップを保存し、Undo／Redoできます。従来のプロジェクトは引き続き読み込めます。

SMFの小節途中の拍子変更は、そのtickで前の小節を区切り、新しい小節として表示します。読込だけでは元のtickは変更しません。拍子設定画面で編集した際は、変更一覧の小節番号に沿って配置し直します。表示が混む短い拍（16分音符基準等）では、ルーラーの拍番号ラベルを小節頭だけに間引きます。拍の区切り線は表示します。

## v0.1.5：複数トラック操作・ソロ／ミュート・試聴・ズーム

### 複数トラックへの音色名適用

左のトラック一覧でShiftクリックすると範囲選択できます。リストはスクロール可能で、16トラックすべて選択できます。「選択 N / 編集 XX」で範囲と編集中のトラックを区別します。ピアノロールで編集するのは、最後にクリックした編集中の1トラックです。

「音色名を適用（選択 N）」は、複数選択時には各トラックに保存済みのBank MSB／LSB／Programから個別に名前を取得します。編集中トラックのBank等を他のトラックへコピーしません。未登録番号は既存名を残し、処理件数をステータスへ表示します。MIDI送信はせず、一括処理全体を1回のUndoで戻せます。入力欄の未確定設定は、先に「設定を適用・音色送信」で確定してください。1トラックだけ選択した場合は、従来どおり入力欄の設定を使用します。

### ソロ／ミュート

トラック一覧の下に `S Solo`／`M Mute` を追加しました。単独選択ならそのトラック、複数選択なら選択全体に適用します。状態が混在する場合は中間状態を表示します。一覧とAll TracksにもS／Mを表示し、鳴らないトラックは暗い色にします。

ソロが1つでもあればソロトラックだけを再生し、その中でもミュートが優先します。複数ソロも可能です。再生中の切替は停止せずに反映し、鳴らさなくなったトラックのNote OffとSustain Offを送ります。解除後は次のノートから参加し、途中まで鳴っていた長音を再発音はしません。コントローラー／Program状態は解除位置まで追跡します。

MIDIチャンネルを複数トラックで共有すると音色やペダル状態も共有されます。特にペダル解除は同じチャンネルの他トラックにも影響します。独立したソロ／ミュートには異なるチャンネルを使用してください。ソロ／ミュート状態は独自プロジェクトに保存し、Undo／Redoできます。SMF出力は編集中の元データを保持するため、ミュートしたトラックのノートもすべて保存します。

### ホイール／トラックパッド

ピアノロール本体・左の鍵盤・ルーラー・Velocityレーン・横スクロールバーにイベントを設定しました。

- トラックパッドの横方向ジェスチャー／横ホイール、およびShift＋ホイール：横スクロール。TkのAqua横方向イベント（Shift-MouseWheel）を明示的に扱います。
- 通常の縦ホイール：上下スクロール。ピアノロール上部の「ホイール横」をオンにすれば、通常ホイールでも横スクロールします。
- ルーラー・Velocityレーン・横スクロールバー上のホイールは横スクロールです。
- ピアノロール、ルーラー、Velocityレーンの横位置は同期します。macOSの小さいdeltaとWindowsの120単位のdeltaを分けて扱います。

### 鍵盤／ノートの試聴

左端の鍵盤を押すと現在のトラックの音色とDefault Velocityで試聴し、離すか鍵盤からフォーカスが外れるとNote Offを送ります。押したまま上下ドラッグで音程を変えられます。ノートをクリックしたときは、そのノート自身の音程とVelocityで短く試聴します。作成／音程ドラッグ時の試聴も維持しています。

再生中も試聴できます。再生スレッドと同じロックでNote On／Offを扱い、演奏中の同一チャンネル・同音程を試聴終了時のNote Offで切らないよう管理します。ソロ／ミュートで鳴らないトラックの試聴も抑制します。試聴はノートデータを追加しません。

### 拡大／縮小

ピアノロール上部に「時間 −／＋」「鍵盤 −／＋」と「100%」を追加しました。時間方向は25〜400%、鍵盤の高さは50〜250%です。中心付近のtick／音高を維持して拡縮します。ノート、グリッド、鍵盤、ルーラー、Velocity、カーソルの座標を同時に更新します。

Ctrl＋ホイールでポインター位置を基準に時間方向を拡縮、Ctrl＋Shift＋ホイールで鍵盤の高さを拡縮できます。「100%」は両方を初期倍率に戻します。ズーム倍率・ホイール横モード・複数選択は独自プロジェクトに保存します。ノートをドラッグしている間はズームしません。縮小時は密すぎる補助グリッド線／拍ラベルを間引きますが、スナップのtick精度は変わりません。

以前のプロジェクトはミュート／ソロなし、100%倍率で読み込めます。新しい依存パッケージは不要です。ソース全体を更新し、次のコマンドで再ビルドしてください。

```bash
.venv/bin/python -m PyInstaller --clean --noconfirm JunoSketch.spec
```
